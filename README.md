# Dayflow · 温和的本地任务规划系统

Dayflow 是一款面向个人的桌面任务规划应用：以"任务日"为核心组织每一天（凌晨 4:00 结算，晚睡也不会把今天算成明天），未完成的事项会温和地带入下一天，而不是变成一堆红色警告。所有数据保存在本机 SQLite 数据库中，无需联网、无账号。

技术栈：React 18 + TypeScript + Vite 前端，Tauri 2 桌面壳，SQLite（tauri-plugin-sql）本地存储。

## 功能一览

- **今日**：关键三件事（每日最多 3 项重点）、时间块拖拽安排（上午 / 下午 / 晚上 / 待安排）、逾期任务温和延续与一键改期、积压洞察（久拖任务的拆分 / 改期 / 放手建议）、今日已完成折叠区（支持恢复 / 撤销执行）、每日复盘与"明日预备"（勾选明日重点、快速安排明天）。
- **日历**：月 / 周 / 日三种视图，拖拽任务卡片即可调整计划日。
- **全部任务**：搜索 + 状态 / 优先级 / 项目 / 标签筛选 + 排序，批量完成 / 改期 / 删除，已完成任务可恢复为进行中。
- **项目**：按项目查看推进进度，支持目标日期与里程碑管理（临近目标会出现在提醒中心）。
- **复盘与统计**：周 / 月切换与历史回看、与上一周期的完成率对比、连续执行天数（streak）、时间去向（按项目 / 标签的投入分布）、近 12 周执行热力图（图表可点击跳转当天）、复盘摘录。
- **提醒中心**：逾期任务、今日截止、项目目标临近、晚间复盘提醒，红点只在有事项时出现。
- **重复任务**：每天 / 工作日 / 每周 / 每月之外，还支持每 N 天、每 N 周并指定星期几、每 N 个月与"每月最后一天"；每次执行以"完成今日执行"记录，历史进展保留在任务时间线中。
- **自然语言快速添加**：在新建窗口输入「明天 下午 跑步 30分钟 #健康 !重要 每周二、四」即可自动解析日期、时段、时长、标签、优先级与重复规则；支持批量导入（多行粘贴逐行解析）与任务模板一键创建。
- **习惯打卡**：重复任务专属视图——近 28 天打卡格、连续天数、本月完成率，点击格子跳转当天。
- **今日手动排序**：拖动任务左侧手柄调整今日计划的执行顺序，顺序按天记忆。
- **命令面板**：Ctrl / ⌘ + K 除了搜任务，还能执行跳转视图、切换主题、切换密度、导出备份等命令。
- **周报 / 月报导出**：统计页一键生成 Markdown 报告，含完成率、专注时长、每日完成清单与复盘摘录。
- **数据安全**：手动导出 / 导入 JSON 备份（导入前确认预览）、本机自动快照（最近 5 份，可一键恢复）、回收站软删除（30 天内可恢复）、保存失败显式提示并可重试、渲染异常兜底页仍可导出数据。
- **桌面体验**：任务到截止时间与晚间复盘时发送系统通知、关闭窗口驻留系统托盘、记住窗口位置与大小、单实例运行（重复启动会唤起已有窗口）。
- **个性化**：主题跟随系统深浅色（也可固定四款主题）、舒适/紧凑两档界面密度、可编辑昵称、键盘快捷键；任务描述支持 Markdown（加粗、列表、链接用系统浏览器打开）；完成全部今日任务有庆祝动效。

### 快捷键

`N` 新建任务 · `T` 回到今天 · `Ctrl / ⌘ + K` 全局搜索与命令面板 · `Ctrl / ⌘ + Z` 连续撤销 · `Esc` 逐层关闭弹层

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 浏览器预览模式（数据存 localStorage）
npm run tauri dev  # 桌面开发模式（数据存 SQLite）
```

浏览器预览模式仅用于快速开发调试；桌面模式下首次启动会自动执行 `src-tauri/migrations/` 中的数据库迁移。开发模式会在数据库为空时载入示例任务。

## 测试与检查

```bash
npm test           # vitest 单元测试（日期结算、重复规则、统计逻辑）
npm run lint       # ESLint
npm run build      # 类型检查 + 前端构建
```

## 构建与发布

```bash
npm run tauri build   # 产出 Windows NSIS 安装包
```

每次 push 会先在 CI 中运行单元测试与 ESLint（quality 任务），通过后才构建安装包。推送 `v*` 标签或手动触发 GitHub Actions 中的 *Build Windows Application* 工作流，可自动构建并发布 GitHub Release。发布流程与版本规则见 [docs/release-process.md](docs/release-process.md)；`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 三处版本号需保持一致。

## 数据存储位置

- 桌面模式：SQLite 数据库 `dayflow.db`，位于 Tauri 应用数据目录（Windows 下为 `%APPDATA%/com.dayflow.planner/`）。
- 自动快照与界面偏好：本机 WebView localStorage。
- 建议定期使用"设置 → 导出备份"生成 JSON 备份文件。

## 目录结构

```
src/
├── App.tsx           # 状态编排与全局交互（快捷键、提醒、确认弹窗、保存队列）
├── components/       # 复用组件（任务详情、编辑器、搜索、提醒中心、确认弹窗等）
├── views/            # 六个主视图（今日 / 日历 / 全部任务 / 项目 / 统计 / 设置）
├── lib/
│   ├── task-date.ts  # 任务日（凌晨 4:00 结算）与日期工具
│   ├── schedule.ts   # 重复规则、到期判断、统计与 streak 纯逻辑
│   ├── storage.ts    # SQLite / localStorage 双模式存储层
│   └── backup.ts     # 自动快照读写
└── data/sample.ts    # 开发模式示例数据
src-tauri/            # Tauri 壳与数据库迁移
```
